# testrepo

## Прототип

`prototype/index.html` — простой прототип «Список задач» в одном HTML-файле, без сборки и зависимостей.
Задачи можно добавлять, отмечать готовыми, удалять и фильтровать (все / активные / готовые);
список сохраняется в `localStorage` браузера.

Открыть: откройте `prototype/index.html` в браузере или запустите `python3 -m http.server -d prototype 8000`
и перейдите на http://localhost:8000.
